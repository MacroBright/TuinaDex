## 1. 硬件连接与电气拓扑

- **驱动供电**：24V DC (推荐 10A 开关稳压电源，各轴驱动板并联供电)；
- **总线拓扑**：线性手拉手拓扑，总线首尾两端各接入 **120Ω 终端电阻**；
- **主机连接**：USB 转 CAN 适配器连接上位机 USB 3.0 接口。

## 2. CAN 地址分配与减速比映射

各关节分配唯一 CAN ID（1~6 号关节映射 CAN ID 0x02~0x07）：

| 关节名称 | CAN ID | 减速比 | 输出方向极性 | 物理位置描述 |
|---|---|---|---|---|
| **J1** | `0x02` | **51 : 1** | 正向 (+1) | 基座水平回转轴 (Yaw) |
| **J2** | `0x03` | **51 : 1** | 反向 (-1) | 大臂主俯仰轴 (Shoulder Pitch, 重力关键) |
| **J3** | `0x04` | **51 : 1** | 反向 (-1) | 小臂肘部俯仰轴 (Elbow Pitch, 重力关键) |
| **J4** | `0x05` | **51 : 1** | 正向 (+1) | 小臂旋转轴 1 (Wrist Roll 1) |
| **J5** | `0x06` | **27 : 1** | 正向 (+1) | 手腕俯仰轴 (Wrist Pitch) |
| **J6** | `0x07` | **51 : 1** | 正向 (+1) | 末端执行器自转轴 (Wrist Roll 2) |

## 3. 驱动器 OLED 参数与首次校准

首次上电或更换电机后，必须在驱动板 OLED 菜单中执行校准：

1. **编码器校准 (Cal)**：
   - 屏幕提示 `Not Cal` 时，按 Enter 键启动自校准；
   - 电机正转一圈 $\to$ 反转一圈，校准完成后蜂鸣提示并存储。
2. **菜单核心参数设定**：
   - `P_Serial` $\to$ `CAN1_MAP`
   - `CAN_Baud` $\to$ `500000` (500 kbps)
   - `ID_Addr` $\to$ 分别设为 `2, 3, 4, 5, 6, 7`
   - `CtrlMode` $\to$ `CR_VFOC` (闭环 FOC 模式)
   - `Checksum` $\to$ `0x6B`

## 4. ZDT 二进制通讯协议帧定义

### 4.1 相对位置控制指令 (`0xFD` 报文, 上位机 $\to$ 驱动器)
用于 50ms 周期闭环下发单步脉冲：

| 字节偏移 | 字段名称 | 类型 | 说明 |
|---|---|---|---|
| Byte 0 | `0xFD` | uint8 | 相对位置运动功能码 |
| Byte 1 | `Direction` | uint8 | 方向标志 (0x00=正向, 0x01=反向) |
| Byte 2~3 | `Speed` | uint16 | 电机最高转速 (RPM, 默认 2000.0) |
| Byte 4 | `Acc` | uint8 | 加速度档位 (0=直冲无延迟) |
| Byte 5~8 | `Pulses` | uint32 | 相对位移脉冲数 (Big-Endian, 65536 脉冲/圈) |
| Byte 9 | `0x6B` | uint8 | 校验和/结束符 |

### 4.2 读取实时位置 (`0x1F` / `0x36` 报文)
- 功能码 `0x36`：查询多圈绝对位置角度（输出 32-bit 有符号脉冲计数）；
- 换算公式：
  $$\text{角度 (deg)} = \frac{\text{Pulses}}{65536.0 \times \text{Reduction Ratio}} \times 360.0$$

## 5. 编码器读数与角度换算 (Anchor 体系)

系统开机时将当前多圈编码器读数作为锚点基准（Anchor 0）：
1. 每次调用 `controller.read_angles()` 读取当前脉冲；
2. 减去开机标定零点脉冲 `anchor_pulses`；
3. 乘以极性符号与减速比系数，得到真实输出轴绝对角度 $\boldsymbol{q} = [q_1, q_2, q_3, q_4, q_5, q_6]$。

## 6. 硬件安全门禁与故障诊断码

驱动器状态字节及安全保护：
- **堵转保护 (Stall Protection)**：持续堵转电流超限时驱动器自动切断 H 桥并回传报错；
- **50ms 通信看门狗**：上位机控制循环每 50ms 下发心跳，若断连驱动器自动减速悬停；
- **急停广播 (E-Stop)**：上位机发送 CAN 标准帧 `0x0000` 广播全轴力矩释放。
